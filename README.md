# Fantasy Draft Helper

A Power Apps Code app which connects to Dataverse, [Sleeper API](https://docs.sleeper.com/) and https://api.server.nbaapi.com/swagger/index.html to support a fantasy NBA draft.

Calls the APIs to get players and their season statistics. Then performs custom calculations that I want for my draft. Then saves these details to Dataverse to display them. Then polls Sleeper every 30s for updates to the currently active Draft.

Built completely from AI prompts and based on the Code Apps starter template.
